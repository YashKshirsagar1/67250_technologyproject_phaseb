Exhibitions

Digital Dreams

Digital Dreams explores how artists are using emerging technologies such as artificial intelligence, virtual reality, and generative algorithms to create immersive artistic experiences. Visitors can interact with installations that respond to movement, sound, and human emotion, transforming traditional gallery spaces into dynamic environments.

Code & Canvas

Code & Canvas highlights the intersection of programming and visual art. This exhibition features works from contemporary artists who use code as a creative medium to generate patterns, animations, and evolving digital landscapes. The exhibition invites visitors to see programming not just as a technical skill, but as a powerful tool for artistic expression.
